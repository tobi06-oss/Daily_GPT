# Phase 1 확장 기능 검증 기록

## 자동 확인
- TypeScript + Vite 빌드: GitHub Actions 최신 실행 결과로 확인
- 신규 데이터 구조: goals, goal_checks, sleep_logs, user_settings
- 기존 localStorage 데이터 로드시 추가 필드 기본값 보강

## 사용자가 확인할 추가 시나리오
1. Today에서 진행 중/다음 일정과 남은 시간 표시
2. Today의 7일 날짜 이동, 일정 점·일기 기분 표시
3. 할 일 완료 시 진행도 즉시 변화
4. 일기 작성칸에 날마다 다른 회고 질문
5. 이틀 연속 기록 시 연속일 표시, 날짜별 지난 오늘 카드
6. '주 3회 러닝' 입력 → 목표 생성
7. 이번 주 일~토 목표 체크, 미래 날짜 불가, 달성/초과 문구
8. '저녁 러닝' 일정에서 러닝 목표 바로 체크
9. 일어났어요/잘게요 현재 시각 기록, 수정 및 삭제
10. 새벽 1시 취침을 전날 날짜로 표시
11. 수면 주간 요약과 평균 기상 시각 확인
12. 설정의 시작 시각, #wake/#sleep/#write/#add 주소 및 이동
13. iPhone Safari에서 단축어 진입과 홈 화면 PWA 저장 공간 차이 확인

## 아직 검증되지 않은 사항
- 실제 iPhone Safari/PWA 단축어 및 잠금화면의 세부 동작
- 주간 수면 통계의 특이 케이스와 일광절약시간제
- 앱 장기 사용과 기존 로컬 데이터 호환성
- 목표 입력의 모든 한국어 변형
- 이미 존재하는 공통 Phase 1의 전체 12개 시나리오 수동 회귀 테스트

실기기 확인 전에는 '완료'로 판정하지 않음
